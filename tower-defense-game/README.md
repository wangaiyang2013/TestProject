# 塔防大战

基于 Canvas 的塔防小游戏，玩法类似经典植物大战僵尸。

## 游戏规则

- **战场**：5 条路 × 26 列长距离场地
- **敌人**：小怪物，无特殊能力，生命 **270**，从右侧生成并向左行走
- **失败条件**：任意小怪物抵达最左端（第 0 列）
- **小推车**：每条路最左侧有一辆小推车；敌人接触后会立即清剿该路全部敌人（每路仅可触发一次）

## 6 种蛇系植物

| 植物 | 阳光消耗 | 说明 |
|------|----------|------|
| 蛇雕师 | 100 | 对左侧敌人造成 20 点伤害，无特殊效果 |
| 蛇阳花 | 50 | 每 15 秒产生 50 阳光 |
| 右蛇射手 | 150 | 对右侧敌人造成 50 点伤害 |
| 左蛇射手 | 150 | 对左侧敌人造成 50 点伤害 |
| 右蛇炮 | 175 | 对右侧敌人造成 50 点伤害 |
| 再生左蛇 | 200 | 对左侧敌人造成 50 点伤害，受伤后 20 秒自动回满生命 |

## 运行方式

直接用浏览器打开 `index.html`，或使用本地静态服务器：

```bash
cd tower-defense-game
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 操作

1. 点击「开始游戏」
2. 在底部植物栏选择植物
3. 点击战场格子放置植物
4. 阻止小怪物突破最左端防线
