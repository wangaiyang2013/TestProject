# 塔防大战

基于 Canvas 的塔防小游戏，玩法类似经典植物大战僵尸。

## 游戏规则

- **战场**：5 条路 × 26 列长距离场地
- **敌人**：小怪物，无特殊能力，生命 **270**，从右侧生成并向左行走
- **失败条件**：任意小怪物抵达最左端（第 0 列）
- **小推车**：每条路最左侧有一辆小推车；敌人接触后会立即清剿该路全部敌人（每路仅可触发一次）

## 6 种蛇系植物

| 植物 | 阳光 | 效果 |
|------|------|------|
| 蛇形雕塑 | 100 | 种植后自动向左侧发射蛇形雕塑，对敌人造成 20 点伤害，无特殊效果 |
| 蛇阳花 | 50 | 种植后每 15 秒产生 50 阳光 |
| 蛇障 | 50 | 原地驻守，阻挡敌人 |
| 蛇坚桩 | 50 | 原地驻守，更高血量阻挡 |
| 缓蛇雕塑 | 100 | 机制同蛇形雕塑，额外附带减速 |
| 蓄蛇雕塑 | 150 | 向左侧发射一枚蛇形雕塑，耗尽后 20 秒恢复，可再次使用 |

## 运行方式

```bash
cd tower-defense-game
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`，或直接打开 `index.html`。

## 操作

1. 点击「开始游戏」
2. 在底部植物栏选择植物
3. 点击战场格子放置植物
4. 阻止小怪物突破最左端防线
