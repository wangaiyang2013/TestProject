# 塔防大战

## 6 种植物（按规格）

| 植物 | 阳光 | 效果 |
|------|------|------|
| 蛇形雕首 | 100 | 种植后，右侧有敌人则自动向右侧发射蛇形雕首，造成 20 点伤害，无特殊效果 |
| 小厨局 | 50 | 种植后，每 15 秒产生 50 阳光 |
| 大铁板 | 50 | 原地驻守，阻挡敌人，自身 4000 生命 |
| 大核弹 | 150 | 3×3 范围爆炸，秒杀范围内敌人 |
| 大汉角 | 175 | 机制同蛇形雕首，命中后额外减速敌人 |
| 战斗引擎 | 150 | 秒杀前方一格敌人，自身爆碎，20 秒后恢复可再次使用 |

## 运行

```bash
cd tower-defense-game
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080` 或 `index.html`。
