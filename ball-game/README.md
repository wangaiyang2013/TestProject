# 双球对战

本地双人对战小游戏，在浏览器中打开即可游玩。

## 操作说明

| 玩家 | 颜色 | 移动 | 攻击 |
|------|------|------|------|
| 玩家1 | 红球 | 方向键 ↑↓←→ | Ctrl |
| 玩家2 | 蓝球 | W / A / S / Z | Y |

## 运行方式

用浏览器直接打开 `index.html`，或使用本地静态服务器：

```bash
cd ball-game
python3 -m http.server 8080
```

然后访问 http://localhost:8080

## 规则

- 向对手发射能量弹，每发造成 15 点伤害
- 生命值归零的一方失败
- 攻击有短暂冷却，朝最后移动方向发射
