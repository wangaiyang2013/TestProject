# 双球对战

本地双人对战小游戏，在浏览器中打开即可游玩。

## 游戏模式

- **双人对战**：两名玩家本地对战
- **训练模式**：你（红球）对战 AI 机器人（蓝球），AI 会自动移动、躲避与攻击
- **组团战斗**：1 人或 2 人组队，击杀怪物获得经验，每关击败 Boss 后抽卡强化，击败 **30 个 Boss** 通关
- **小球英雄**：仅需限时选球（超时随机）；双球自动持续反弹对打，技能自动释放；**铁壁丸**（受击减伤 90%、攻击必暴击）、喷火球、尖刺球、斷刀球等；训练场与双人模式
- **西部斗牛球**：鼠标移动，左键朝鼠标瞄准射击；配备斗牛犬手枪，命中造成伤害，**距离越远伤害越低**
- **数字老师**：头顶数字自动追踪敌人，命中伤害=数字，命中后数字+1（无上限）；训练场与双人模式
- **自定义模式**：玩法同小球英雄；自创球房间可自由输入名称（12字）、技能名（字数不限）、装饰、伤害（≤100）、间隔（0.5–5秒）等；训练场与双人模式

## 操作说明

| 玩家 | 颜色 | 移动 | 攻击 |
|------|------|------|------|
| 玩家1 / 你 | 红球 | 方向键 ↑↓←→ | Ctrl |
| 玩家2（仅双人） | 蓝球 | W / A / S / Z | Y |

## 运行方式

用浏览器直接打开 `index.html`，或使用本地静态服务器：

```bash
cd ball-game
python3 -m http.server 8080
```

然后访问 http://localhost:8080

## 金币与商店

- 每完成一局可获得 **本局价值 50%** 的金币（基础 200，胜利额外 +100）
- 主菜单进入 **商店**，可购买皮肤、配饰、自创球
- **需先完成一局** 后才可购买
- 购买的 **自创球** 会加入 **小球英雄** 选球列表

## 规则

- 向对手发射能量弹，每发造成 15 点伤害
- 生命值归零的一方失败
- 攻击有短暂冷却，朝最后移动方向发射
