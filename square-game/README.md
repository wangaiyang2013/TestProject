# Square Game

小方块无尽跑酷：自动向前奔跑，**点击或触摸屏幕**让方块跳跃，躲开地面上的障碍。

## 玩法

- 方块会自动向右奔跑
- 点击画面、触摸屏幕，或按空格 / 上方向键跳跃
- 碰到障碍则游戏结束，可点击「再玩一次」重新开始

## 本地运行

在项目目录启动静态服务器，例如：

```bash
cd square-game
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080` 即可游玩。也可直接用浏览器打开 `index.html`（部分环境对本地文件有限制，推荐用上述方式）。

## 文件结构

- `index.html` - 页面入口
- `styles.css` - 全屏样式与 UI
- `game.js` - 游戏逻辑（Canvas）
